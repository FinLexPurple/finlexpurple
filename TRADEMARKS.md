# FinLexPurple Trademark Policy

"FinLexPurple", the FinLexPurple name, and the FinLexPurple logo (the "Marks") are
trademarks of the FinLexPurple project and its maintainers. This is a short,
good-faith policy; it is not legal advice.

## Code license vs. trademark

The FinLexPurple source code is licensed under the Apache License 2.0. **That license
covers the code, not the Marks.** Apache-2.0 explicitly does not grant permission to
use the project's trade names, trademarks, or product names (see Apache-2.0 §6). This
policy explains the limited use of the Marks that we do permit, so that the name keeps
pointing to this project and is not used in ways that mislead people.

## Uses that are always fine (no permission needed)

- **Referring to the project**, truthfully and descriptively: "built with FinLexPurple",
  "compatible with FinLexPurple", "a security scan using FinLexPurple", "a fork of
  FinLexPurple".
- **Unmodified distribution**: redistributing official, unmodified releases under their
  original name.
- **Writing, talks, and teaching** about FinLexPurple that use the name to identify the
  project.

Please use the Marks only to refer to the project, keep the spelling and capitalization
("FinLexPurple"), and don't make the Marks the most prominent element of your own
materials.

## Uses that need our permission, or that we ask you not to make

- **Don't imply endorsement, affiliation, or official status.** Don't use the Marks (or
  confusingly similar names) for your company, product, service, domain name, social
  account, or event in a way that suggests it is produced, sponsored, or approved by the
  FinLexPurple project when it is not.
- **Don't ship a modified version under the FinLexPurple name.** If you distribute a
  changed build, a repackage, or a fork with meaningful differences, **give it a
  different name** so users don't mistake it for an official release. You may still state,
  descriptively, that it is "based on FinLexPurple".
- **Don't use the Marks as your package or namespace identity** on a registry (PyPI,
  npm, container registries, etc.) in a way that could be mistaken for an official
  FinLexPurple distribution. (This also protects users from dependency-confusion and
  typosquatting.)
- **Don't alter the Marks** — no modified logos, and no combining the name with your own
  to form a new mark (e.g. "FinLexPurple Pro", "SuperFinLexPurple").

## Questions

If you want to use the Marks in a way this policy doesn't clearly allow — a partnership,
an integration you want to call "official", merchandise, or anything you're unsure about
— please ask the maintainers first. We're happy to work it out in good faith.
